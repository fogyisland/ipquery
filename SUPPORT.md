# Support

## Community Support (free)

- GitHub issues at the project repository.
- Community-maintained `docs/superpowers/specs/` and the README's
  "First-deploy guide" walk-through.

No SLA. Best-effort responses from maintainers and contributors.

## Commercial Support

For production deployments, custom integrations, or compliance review,
contact **sales@example.com** for a quote.

Available offerings:

| Plan           | Audience                            | Includes                                                                           |
| -------------- | ----------------------------------- | ---------------------------------------------------------------------------------- |
| **Community**  | Hobbyists, side projects            | GitHub issues, public roadmap                                                      |
| **Standard**   | Startups, single-team production    | Email support, 1-business-day response, security advisories                        |
| **Enterprise** | Regulated, multi-team, multi-region | Slack channel, 4-hour response, signed releases, custom SLA, on-call for incidents |

All plans include access to the same MIT-licensed source code. The paid
tiers cover **support**, not the code itself.

## Common Topics

- **First-deploy help** — walk-through of the README's "First-deploy guide"
  on your target environment.
- **MaxMind registration** — guide you through the free GeoLite2 signup and
  verifying that `MAXMIND_LICENSE_KEY` works on your instance.
- **Migrations** — review of your MySQL version, character set, and
  recommended `innodb_*` settings.
- **Compliance review** — read-only review of your instance against an
  internal security checklist before a production cutover.

## What Support Does Not Cover

- Geolocation accuracy of the upstream data sources.
- Upstream provider outages (MaxMind, DB-IP).
- Modifications to upstream data or licensing terms.
